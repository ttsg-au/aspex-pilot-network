Import flights

From the drone PC: plug the controller into the PC by USB, then double-click Import Flights on the desktop. It copies new records off the controller into Dropbox, sends them here, and opens this page. It closes itself when done.

Turn the drone on too. With most DJI controllers the flight files only show up on the PC while the drone is switched on and linked to the controller. If Import Flights finds no files, power the drone on, wait for it to link, and run it again.

Download Import Flights (once per PC; save it to the desktop). It contains this logbook's upload key, so keep it to your own PCs.
